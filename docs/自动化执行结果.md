### EP4 plan PT 文件说明

EP4 plan 是单独的 PyTorch `dict` 文件，不是模型权重。它记录了从指定 Scores 和剪枝配置生成的确定性执行方案，主要包括：

- 每层、每专家、每通道的布尔 mask（`intermediate_masks`）及每个专家的保留宽度（`expert_widths`，0 表示删除该专家）。
- 每层的 `expert_to_rank`、`expert_to_local_id`、`local_to_global` 和 `rank_widths`，即专家在四张 GPU 上的放置和本地编号。
- requested/actual prune ratio、各 rank 的负载和偏差、贪婪排列、局部搜索次数、求解器状态，以及源 Scores 路径/SHA256 和剪枝配置。

例如 Qwen p30 的 mask shape 是 `[48, 128, 768]`，即 48 层、每层 128 个专家、每专家 768 个中间通道；其 `placement_method=greedy`，之后再做 coordinate-descent local search。

贪婪规划本身约 7--10 秒，理论上可以在每次评测前重算，所以保存 PT 不是为了显著节省时间。仍然单独保存是为了固定 Scores 版本、mask、专家映射、GPU placement 和剪枝配置，避免 Scores 或代码变化造成结果漂移，同时让规划与评测解耦、可审计、可完整复现。
